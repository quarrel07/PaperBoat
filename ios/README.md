# App icon

`Assets.car`, `Paperboat60x60@2x.png` and `Paperboat76x76@2x~ipad.png` are generated files. Don't edit them here.

The icon's source is `macosx/Paperboat.icon` (Icon Composer), shared by the macOS and iOS apps. Its editable artwork is `macosx/Paperboat.pxd` (Pixelmator Pro). After changing the icon, run `macosx/update-app-icons.sh` (needs Xcode 27 or later) to regenerate these files and the macOS ones, then commit them.
