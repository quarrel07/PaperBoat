# App icon

`Assets.car` is a generated file. Don't edit it here.

The icon's source is `macosx/Paperboat.icon` (Icon Composer), shared by the macOS and iOS apps. Its editable artwork is `macosx/Paperboat.pxd` (Pixelmator Pro). After changing the icon, run `macosx/update-app-icons.sh` (needs Xcode 27 or later) to regenerate it and the macOS files, then commit them.
